# Code of Conduct

## Our pledge

We as members, contributors, and maintainers pledge to make participation in the
governor project a harassment-free experience for everyone, regardless of age,
body size, visible or invisible disability, ethnicity, sex characteristics,
gender identity and expression, level of experience, education, socio-economic
status, nationality, personal appearance, race, religion, or sexual identity and
orientation. We pledge to act and interact in ways that contribute to an open,
welcoming, diverse, inclusive, and healthy community.

## Our standard

This project adopts the **[Contributor Covenant](https://www.contributor-covenant.org),
version 2.1**, as its code of conduct. The full text — including the expected
behaviors, unacceptable behaviors, enforcement responsibilities, scope, and
enforcement guidelines (Correction → Warning → Temporary Ban → Permanent Ban) —
is published at:

- <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Plain text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt>

In short: be respectful, assume good faith, give and gracefully accept
constructive feedback, focus on what is best for the community, and show empathy
toward others. Harassment, personal attacks, and other unacceptable behavior
described in the Covenant are not tolerated.

## Scope

This Code of Conduct applies within all project spaces (the repository, issues,
pull requests, and discussions) and when an individual is officially
representing the project in public spaces.

## Enforcement

This is a solo-maintained portfolio project. Instances of abusive, harassing, or
otherwise unacceptable behavior may be reported to the project maintainer by
opening a confidential report through GitHub (contact the repository owner,
**@billdmar**). All complaints will be reviewed and investigated promptly and
fairly, and the maintainer will respect the privacy and security of the reporter.
